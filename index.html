🔄 交叉分类法示例

Na₂CO₃（纯碱）从不同角度可同时属于：
• 按阳离子 → 钠盐
• 按阴离子 → 碳酸盐
• 按酸碱性 → 正盐
• 按溶解性 → 可溶性盐
💡 同一物质可以有多种分类归属，这就是交叉分类法的意义——弥补树状分类法单一标准的局限。

📋 电解质 vs 非电解质 判定表

类别定义典型物质注意
电解质在水溶液中或熔融状态下能导电的化合物酸、碱、盐、H₂O、多数金属氧化物必须是化合物；导电的是其自身电离出的离子
非电解质在上述两种情况下都不能导电的化合物酒精(C₂H₅OH)、蔗糖(C₁₂H₂₂O₁₁)、CO₂、SO₂、NH₃CO₂水溶液导电是因为生成了H₂CO₃，CO₂本身是非电解质
既不是也不是单质和混合物不属于此分类范畴Cu、石墨、NaCl溶液、盐酸电解质/非电解质只针对纯净物中的化合物

🎯 实验目的：观察复分解型离子反应的现象（沉淀/气体/水）；掌握离子方程式"写→拆→删→查"四步书写法。
选择反应后点击"倾倒混合"观察现象。

📝 离子方程式书写规则速查

可拆：强酸(HCl/H₂SO₄/HNO₃)、强碱(NaOH/KOH/Ba(OH)₂/Ca(OH)₂)、可溶性盐
不可拆（保留化学式）：沉淀↓、气体↑、H₂O、单质、氧化物、弱酸(CH₃COOH/H₂CO₃)、弱碱(NH₃·H₂O)
微溶物：作反应物时若为澄清溶液则拆，若为浊液则不拆；作生成物时一律不拆（视为沉淀）
⚠ Ca(OH)₂：澄清石灰水→拆；石灰乳/悬浊液→不拆

⚡ 氧化还原反应分析 双线桥法

🎯 学习目标：用化合价升降判断氧化还原反应；用双线桥标出电子转移方向和数目；准确判断氧化剂与还原剂。

🔑 核心口诀与规律

升失氧还，降得还氧：
化合价升高 → 失去电子 → 被氧化 → 作还原剂
化合价降低 → 得到电子 → 被还原 → 作氧化剂

四大基本反应类型与氧化还原的关系：
• 置换反应 → 一定是氧化还原反应
• 复分解反应 → 一定不是氧化还原反应
• 化合反应 / 分解反应 → 可能是也可能不是（看有无单质参与或生成≠判断依据，唯一依据是化合价是否变化）
